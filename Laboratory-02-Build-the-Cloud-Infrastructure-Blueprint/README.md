# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on understanding and documenting the basic components of cloud infrastructure. Using the KillerCoda Linux environment, system resources were investigated and related to fundamental cloud computing concepts.

The activity also includes identifying cloud infrastructure components, comparing AWS, Microsoft Azure, and Google Cloud services, designing a simple cloud architecture, and documenting the laboratory experience using Markdown and GitHub.

## Objectives

The objectives of this laboratory activity are:

1. Investigate the resources available in a Linux cloud environment.
2. Identify compute, storage, networking, and operating system components.
3. Compare equivalent infrastructure services offered by AWS, Microsoft Azure, and Google Cloud.
4. Design a simple cloud infrastructure architecture.
5. Practice technical documentation using Markdown.
6. Improve the organization of a cloud computing laboratory portfolio using GitHub.

## Cloud Infrastructure Components

The major infrastructure components investigated in this laboratory are:

- Compute Resources
- Storage Resources
- Networking Resources
- Operating System
