# Mission 9 Reflection: The Cloud Automation Engineer

## 1. Why is automation critical when managing hundreds of cloud servers?

Automation helps administrators manage many servers without repeating the same commands manually. It saves time, keeps procedures consistent, and reduces mistakes caused by repetitive work. For example, a scheduled backup can protect important files even when the IT staff forgets to perform the task.

## 2. What are the potential dangers of automation?

Automation can cause serious damage when a script contains an incorrect or destructive command. If that script runs on 1,000 servers, one mistake could affect many systems at the same time. This is why scripts must be reviewed, tested, and monitored before being used in a large environment.

## 3. How did Bash scripting differ from Docker Compose YAML?

Docker Compose YAML describes how containers, services, and their configurations should work together. Bash scripting focuses on executing commands in order and using conditions to decide what happens next. Through this activity, I learned that both tools are useful, but they solve different problems in cloud administration.

## 4. How has my understanding of Cloud Computing changed from Laboratory 1 to Laboratory 9?

From Laboratory 1 to Laboratory 9, I progressed from learning basic Linux commands and cloud concepts to exploring storage, containers, deployment, security, monitoring, and automation. I realized that cloud computing requires more than setting up an application. It also involves protecting data, managing resources, and keeping services dependable.

## 5. Which cloud role did I enjoy the most and why?

I enjoyed the Cloud Automation Engineer role because I saw how a simple script can handle a task that would otherwise require repeated manual work. Creating the backup script helped me understand how administrators can make their daily responsibilities more efficient. I also learned that automation must be used carefully because a repeated mistake can cause serious problems.

Overall, this mission helped me connect the Linux commands from earlier laboratories with a practical task. I learned that successful cloud operations depend on automation, testing, and proper documentation. These skills can help me become more prepared for future IT work.
