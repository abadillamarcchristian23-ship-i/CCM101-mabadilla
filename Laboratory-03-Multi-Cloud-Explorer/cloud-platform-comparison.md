
# Cloud Platform Comparison

## AWS vs Microsoft Azure vs Google Cloud

| Category            | AWS                                        | Microsoft Azure                  | Google Cloud Platform                          |
| ------------------- | ------------------------------------------ | -------------------------------- | ---------------------------------------------- |
| Launch Year         | 2006                                       | 2010                             | 2008                                           |
| Compute Service     | Amazon EC2                                 | Azure Virtual Machines           | Compute Engine                                 |
| Storage Service     | Amazon S3                                  | Azure Blob Storage               | Cloud Storage                                  |
| Networking Service  | Amazon VPC                                 | Azure Virtual Network            | Virtual Private Cloud (VPC)                    |
| Identity Service    | AWS IAM                                    | Microsoft Entra ID               | Google Cloud IAM                               |
| Primary Strength    | Broad cloud service ecosystem              | Microsoft enterprise integration | AI, data, and Kubernetes                       |
| Ideal Organizations | Startups, enterprises, global applications | Microsoft-based organizations    | AI/data-focused and cloud-native organizations |

## 1. Which cloud provider offers the broadest range of services?

**AWS** is my choice for the provider with the broadest overall range of cloud services. It covers a very wide variety of computing, storage, databases, networking, security, analytics, and application requirements, giving architects many possible combinations when designing a system.

## 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** is the strongest choice for Microsoft integration. Organizations using Windows Server, Microsoft 365, Microsoft SQL Server, and Microsoft identity technologies can connect their existing environment with Azure with less architectural friction.

## 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud** is my choice for this category because of its strong focus on AI, machine learning, data processing, and Kubernetes. Its Google Kubernetes Engine is particularly useful for organizations that want managed Kubernetes for containerized applications.

## 4. Which cloud platform would you personally choose and why?

Personally, I would choose **AWS** because it provides enough flexibility for different types of projects. As an IT student, I also see value in learning a platform with a wide selection of services because the same knowledge can be applied to websites, databases, storage, networking, security, and cloud infrastructure.

# Checkpoint 5 – Equivalent Cloud Services

| Service Category    | AWS        | Azure                          | GCP                            |
| ------------------- | ---------- | ------------------------------ | ------------------------------ |
| Virtual Machine     | Amazon EC2 | Azure Virtual Machines         | Compute Engine                 |
| Object Storage      | Amazon S3  | Azure Blob Storage             | Cloud Storage                  |
| Identity Management | AWS IAM    | Microsoft Entra ID             | Google Cloud IAM               |
| SQL Database        | Amazon RDS | Azure SQL Database             | Cloud SQL                      |
| Kubernetes          | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## Summary

Although the three providers use different product names, their basic cloud functions are very similar. For example, EC2, Azure Virtual Machines, and Compute Engine all provide virtual machines, while EKS, AKS, and GKE provide managed Kubernetes environments.

The major difference is not simply whether a service exists, but how each provider implements it, prices it, integrates it with other services, and fits a particular organization's requirements.
