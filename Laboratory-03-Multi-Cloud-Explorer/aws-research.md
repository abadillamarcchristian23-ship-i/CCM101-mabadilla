
# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides a large collection of cloud services that organizations can use to build, deploy, store, secure, and manage applications without owning all of the physical infrastructure.

AWS is widely used by startups, enterprises, government organizations, and developers because it supports many different workloads, from simple websites to large-scale distributed systems.

## Global Infrastructure

AWS organizes its infrastructure into **Regions** and **Availability Zones**. A Region represents a separate geographic area, while Availability Zones are isolated locations within a Region. AWS recommends using multiple Availability Zones when high availability is important because an application can continue operating even if one Availability Zone experiences a failure.

AWS also provides additional infrastructure options such as Local Zones and Wavelength Zones for workloads that need resources closer to end users.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to create and manage AWS resources. Users can access services such as EC2, S3, IAM, databases, networking, monitoring, and billing through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications, websites, databases, and other workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used for files, backups, media, documents, datasets, and application data.

### 3. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources. It allows administrators to manage users, roles, permissions, and policies.

### 4. Amazon RDS

Amazon Relational Database Service (RDS) provides managed relational databases. It reduces the amount of manual administration required for database deployment, backups, and maintenance.

## Three Advantages

1. **Large service selection** – AWS provides services for computing, storage, networking, databases, security, analytics, AI, and many other workloads.
2. **Global infrastructure** – AWS has a large geographic infrastructure that allows applications to be deployed closer to their users.
3. **Scalability** – Resources can be increased or decreased depending on application demand, which is useful for businesses with changing workloads.

## Typical Enterprise Use Cases

AWS can be used by enterprises for:

* Hosting websites and web applications
* Data backup and disaster recovery
* Enterprise databases
* E-commerce platforms
* Artificial Intelligence and Machine Learning
* Big data processing
* Application development and testing
* Global application deployment

## Conclusion

AWS is a strong general-purpose cloud platform because it combines a large service catalog with extensive infrastructure and flexible deployment options. It is particularly suitable for organizations that want many choices when designing their cloud architecture.
