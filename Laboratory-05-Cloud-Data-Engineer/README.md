
# Laboratory 05: The Cloud Data Engineer

## Mission Overview

This laboratory explores how cloud applications store and manage unstructured data. I deployed MinIO using Docker and configured a basic object storage environment for a photo-sharing application. The activity also involved creating a bucket, uploading a sample object, and documenting the deployment process.

## Objectives

* Compare Block Storage, File Storage, and Object Storage.
* Deploy a MinIO server using Docker.
* Access a storage management console through port forwarding.
* Create the `client-photos` bucket.
* Upload a sample file and verify that it is stored successfully.
* Document the activity using Markdown and screenshots.

## Tools Used

* **KillerCoda:** Provided the Linux playground for the deployment.
* **Docker:** Downloaded and ran the MinIO container.
* **MinIO:** Provided the S3-compatible object storage service.
* **Web Browser:** Used to access the management console.
* **GitHub:** Used to maintain the laboratory files and evidence.
* **Markdown:** Used to prepare the technical documentation and reflection.

## Skills Learned

Through this activity, I learned how object storage differs from other storage types and how a Docker container can provide a dedicated storage service. I also practiced configuring environment variables, mapping network ports, managing a bucket, uploading an object, and organizing technical documentation in a GitHub repository.
